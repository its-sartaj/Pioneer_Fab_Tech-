## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/its-sartaj/Pioneer_Fab_Tech-.git
   cd Pioneer_Fab_Tech-
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
